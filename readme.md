# FollowChecker

**Instagram 언팔 체크 프로그램**
나를 팔로우하지 않는 사람을 자동으로 찾아줍니다.

---

## 소개

Followchecker는 Instagram에서
- 내 팔로워 목록
- 내 팔로잉 목록
을 긁어와서,
**"나는 팔로우했지만, 나를 팔로우하지 않는 사람"** 을 자동으로 찾아줍니다. 쿠키를 이용한 자동로그인을 이용하여 여러번 로그인 해야하는 번거로움을 줄였습니다.하지만 Instagram의 철저한 자동화 프로그램 검열로 인하여, 수동 스크롤을 통해 Instagram에서 팔로우, 팔로잉 정보를 긁어오는 것은 불가피하게 되었습니다.

---

## 주요 기능

- 인스타그램 로그인 (쿠키 이용)
- 팔로워 목록 긁기
- 팔로잉 목록 긁기
- 팔로워와 팔로잉 목록을 비교
- 나만 팔로우하는 사람 목록을 저장

---

## 설치 방법

1. Python 3.8 이상 설치
2. 필요한 라이브러리 설치

```bash
pip install -r requirements.txt
python -m playwright install
```

---

## 사용법

1. 쿠키 저장
   - `save_cookies.py`를 실행하고 직접 로그인 후 쿠키 저장

2. 팔로워 목록 긁기
   - `scrolling_followers.py` 실행
   - 팔로워 팝업창에서 수동으로 스크롤 끝까지 내려주세요.

3. 팔로잉 목록 긁기
   - `scrolling_followings.py` 실행
   - 팔로잉 팝업창에서 수동으로 스크롤 끝까지 내려주세요.

4. 비교 및 결과 확인
   - `compare_followers_followings.py` 실행
   - `not_following_back.txt` 파일에 결과가 저장됨

---

## 주의사항

1. 수동으로 스크롤할때 스크롤을 끝까지 내려야 모든 팔로워/팔로잉 정보를 정확히 가져올 수 있습니다.
2. 너무 자주 실행하거나 로그인 반복 시 Instagram 계정이 잠길 수 있습니다.
3. 이 프로그램은 본인 계정을 기준으로 작성되었습니다.  
   기술적으로 타인의 팔로워/팔로잉 목록에도 적용할 수 있으나,
   타인의 개인정보 및 프라이버시 보호를 위해 타인 계정에 대한 사용은 자제해주시기 바랍니다.
